# Gaia Dynamics: Catalog Tariff Scan landing page

A proposed landing page for [gaiadynamics.ai](https://www.gaiadynamics.ai), built as part of an SEO audit and growth plan.

Gaia already sells a catalog tariff scan (upload a product list, get tariff rates for the whole catalog), but the feature only appears as one line on `/product/tariffs`. This page gives that high-intent use case its own URL, targeting **bulk HTS classification** and related searches, with the technical SEO the current site is missing.

Proposed URL: `https://www.gaiadynamics.ai/product/catalog-tariff-scan`

## What the page includes

- One H1 that answers the search query in the first paragraph, with a logical H2/H3 structure
- Title (53 characters), meta description and canonical URL
- Open Graph and Twitter preview image (`app/opengraph-image.png`); the live site currently has none on any page
- Structured data: `WebPage`, `BreadcrumbList`, `SoftwareApplication` and `FAQPage`
- `robots.txt` and `sitemap.xml` generated by Next.js
- Brand match: Inter, Gaia indigo `#4F46E5`, Gaia logo, navigation and footer
- Accessibility: skip link, keyboard-operable switches and FAQ, visible focus, reduced-motion support

Every product fact comes from gaiadynamics.ai. Sources are noted in `app/lib/site.ts`.

## Run locally

Requires Node.js 18.18 or later.

```bash
npm install
npm run dev
```

Open http://localhost:3000. For a production build: `npm run build && npm start`.

## Deploy on Vercel

1. In Vercel, choose **Add New > Project** and import the GitHub repository.
2. Vercel detects Next.js automatically. Keep the default build settings.
3. Click **Deploy**. No environment variables are needed for a preview.

### Indexing

The preview is set to `noindex` and `robots.txt` blocks crawling, so a `vercel.app` copy never competes with Gaia's own site. The canonical URL already points at the proposed Gaia URL.

When the page ships on gaiadynamics.ai, set this environment variable to make it indexable:

```
NEXT_PUBLIC_ALLOW_INDEXING=true
```

## Stack

Next.js 15.5 (App Router), React 19.1, TypeScript. No UI libraries and no client-side tracking. The only client component is the tariff-layer switch.

Concept page prepared for an assessment. Not an official Gaia Dynamics page.
